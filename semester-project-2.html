Semester project 2

Is an auction house student-only website where users can create listings, place bids using virtual credits.

About the project

In this project I learned to use HTML5, CSS3, Tailwindcss v4 framework, vanilla JavaScript. A auction house website for students, a visitor can browse the items only, a registered user can create a listing, edit/delete their listing, bid on a item, view bid history. In profile it shows how many listings you have, bids and wins. You can also change your avatar and banner image in the profile.
